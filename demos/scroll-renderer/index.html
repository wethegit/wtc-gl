wtc-gl / ScrollRenderer
Scene 1 — plasma

ScrollRenderer

A single WebGL canvas fixed to the page, rendering independent scenes anchored to DOM elements via getBoundingClientRect.

Scene 2 — rings

Scroll-linked viewports

Each scene tracks its element's bounding rect every frame. Scissor testing clips each render to the element's exact screen position.

Scene 3 — grid

One render loop

All scenes share a single renderer and RAF loop. Off-screen scenes are culled automatically via IntersectionObserver.

Scene 4 — particles

DOM-anchored elements

Any element in your layout can be a GL anchor. Here a particle field tracks the right panel independently from the page copy beside it.
